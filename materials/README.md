# Study materials

| File | Content |
|---|---|
| `app_texts_en.md`, `app_texts_de.md` | Participant-facing texts of the app, verbatim from its English and German message catalogues. They include the screening question, the **informed-consent text**, the **intake questionnaire** (household size, dwelling type, age bracket, with response formats), the nudge-phase introduction, the window banners, the "Not the best time right now" dialog, the score feedback, the background information page, help and retrospective-entry texts. |
| `statistical_analysis_plan_v1.0.md` | Statistical analysis plan, version 1.0, locked on 24 September 2026. As the paper states, it was written after data collection and after a crude phase-by-window count table had been seen, but before any model was fitted. It is not a preregistration. |
| `screenshots/` | Screenshots of the deployed app, taken with the app's test account on a smartphone. The phone's status and navigation bars were cropped off. The `studyAdmin_*` screens show a debug control that forces a window for the screenshots. The app displays it only to the test account, so participants never saw it. Figure 1 of the paper crops five of these screens (`analysis/figure_system.py`). |

The consent screen shows three statements, `point1`, `point2` and `point4`. The catalogue contains no `point3`.
